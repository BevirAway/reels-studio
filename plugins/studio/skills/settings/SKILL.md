# Налаштування студії

Інструмент — `~/.studio/bin/studio` (`status`, `module on|off <модуль>`, `key set|del|test <NAME>`, `doctor`, `update`).
Вікна з галочками — ярлик «Налаштування студії» в робочій папці (можна відкрити: `open "<папка>/Налаштування студії.command"`).

Модулі: `montage` — монтаж рілсів · `voice` — чистка голосу · `upscale` — покращення якості відео · `sounds` — звуки ·
`texts` — тексти, каруселі, контент-план · `research` — дослідження Instagram (ключ Apify) · `publish` — публікація
(Instagram, Telegram).

- **Що вмієш:** перелічити увімкнене простими словами з прикладами фраз («зроби рілс з відео у Вхідних»), вимкнене —
  одним рядком «ще можу …, якщо увімкнути».
- **Увімкнути модуль:** сказати, що докачається (розмір, час), і з її згоди `studio module on <модуль>` у фоні; після —
  попросити почати нову розмову (Claude підхоплює модулі на старті).
- **Ключ:** вона вставляє ключ у чат → `printf %s '<ключ>' | studio key set <NAME>` → результат перевірки; сам ключ у
  відповіді не повторювати. Де взяти: ElevenLabs — elevenlabs.io → Settings → API Keys; Apify — console.apify.com →
  Settings → Integrations; Instagram і Telegram — навичка `publish:setup`.
- **Не працює:** `studio doctor` → пояснити й полагодити (`studio module on <модуль>` докачує відсутнє).
- **Оновити:** `studio update` (5–15 хв), потім нова розмова.
