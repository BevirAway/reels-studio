# Підключити публікацію

Вести по одному кроку, чекати «готово», не вивалювати всю інструкцію одразу. Ключі вона вставляє в чат — одразу
зберегти `~/.studio/bin/studio key set <NAME>` (через stdin), не повторювати їх у відповіді й не писати у файли.
Складно або щось не збігається з інструкцією (Meta часто міняє екрани) — запропонувати зробити це разом з Нікітою.

## Telegram-канал (5 хв)
1. У Telegram відкрити @BotFather → `/newbot` → назва → нік, що закінчується на `bot` → він дасть токен → вставити
   сюди → `studio key set TG_BOT_TOKEN`.
2. Канал → Керування каналом → Адміністратори → Додати адміністратора → знайти свого бота → дозволити «Публікувати
   повідомлення».
3. Нік каналу (`@назва`) або, якщо канал приватний, переслати будь-який пост каналу боту @userinfobot і взяти ID
   (`-100…`) → `studio key set TG_CHANNEL`.
4. Перевірка: `publish.py setup-tg`.

## Instagram (15–30 хв, один раз)
Потрібно: професійний акаунт Instagram (Автор або Бізнес): Instagram → Налаштування → Тип акаунта → Перейти на
професійний. Facebook-сторінка не потрібна.
1. developers.facebook.com → увійти через Facebook → My Apps → Create App → тип «Business» (або use case «Manage
   messaging & content on Instagram») → назва будь-яка.
2. У застосунку: продукт **Instagram** → «API setup with Instagram login».
3. Roles → Instagram Testers → додати свій нік Instagram. Потім в Instagram: Налаштування → Сайти й застосунки →
   Запрошення тестувальника → Прийняти.
4. Повернутися в «API setup with Instagram login» → «Generate access token» біля свого акаунта → увійти в Instagram →
   дозволити → скопіювати токен → вставити сюди → `studio key set IG_TOKEN`.
5. Перевірка: `publish.py setup-ig` (збереже ID акаунта). Токен живе 60 днів, студія оновлює його сама при публікаціях.
Застосунок лишається в режимі розробки — для публікації у свій акаунт перевірка Meta не потрібна.

## Після
`publish.py schedule-on` (з її згоди: «Увімкнути публікацію за розкладом? Mac має бути увімкнений у цей час.») і
записати в `Профіль/профіль.md`, куди публікуємо автоматично, а куди — пакетом вручну.
