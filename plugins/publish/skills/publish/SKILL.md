# Публікація

Інструмент — `~/.studio/bin/py ${CLAUDE_PLUGIN_ROOT}/scripts/publish.py` (команди в заголовку). Черга —
`Публікації/черга.json`. Не підключено Instagram/Telegram (`studio status` — немає IG_TOKEN/TG_BOT_TOKEN) — навичка
`publish:setup`.

## Порядок (MANDATORY)
1. Зібрати: файл(и) з `Готово/`, текст `Публікації/<дата> <назва>.md` (блоки `## INSTAGRAM`, `## TELEGRAM`; навичка
   `texts:captions`), обкладинка рілса (необов'язково), куди і коли.
2. **Показати їй рівно те, що піде:** мережі, дата й час, назва файлу, повний текст кожній мережі. Спитати «Публікуємо?».
3. Лише після явного «так» на це: `publish.py add --when "РРРР-ММ-ДД ГГ:ХХ" --to ig,tg --files … --text …` (або
   `--when now` + `publish.py now <id>`). Змінився текст чи файл після «так» — показати й спитати знову.
4. Розклад: якщо `schedule-on` ще не вмикали — увімкнути (кожні 5 хв перевіряє чергу; Mac має бути увімкнений).
5. Після публікації — посилання їй. Помилка — `publish.py list`, пояснити простими словами і що зробити.

## Обмеження
- Instagram: відео 9:16, до 15 хв (рілси — до 90 с найкраще), H.264 + AAC; до 100 публікацій через API на добу.
  Обкладинка — `--cover` (JPG 1080x1920). Відео йде через тимчасове посилання (1 год) — так влаштований API.
- Telegram: файл до 50 МБ (більше — `phone_copy.sh`), підпис до 1024 знаків (довше — окремим повідомленням).
- TikTok, YouTube Shorts, Facebook, Threads — автоматично не публікуємо: зібрати пакет у `Готово/<дата> <назва>/`
  (відео + `підписи.md` з текстом під кожну мережу) і сказати, що можна завантажити з телефона.
