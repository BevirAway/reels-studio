# Чистка голосу

1. Звук з відео: `~/.studio/bin/ffmpeg -i <відео> -vn -ac 1 -ar 48000 <робоча папка>/raw.wav`.
2. `~/.studio/bin/py ~/.studio/repo/plugins/montage/scripts/voice.py raw.wav clean.wav` — Resemble Enhance → highpass
   70 Гц → гучність −13 LUFS, без компресора. Повільно: ~1 хв на хвилину звуку (перший запуск довше).
3. Перевірити розшифровкою, що слова на місці (`stt.py` модуля монтажу). Зникли слова (кілька голосів, сміх,
   музика) — `voice.py … --plain`.
4. Якщо треба відео з чистим звуком: `ffmpeg -i <відео> -i clean.wav -map 0:v -map 1:a -c:v copy -c:a aac -b:a 192k
   -shortest Готово/<назва>.mp4`.
Живі звуки кадру (кроки, яблука, листя) Resemble лишає — це добре. Сервіси, що вирізають усе, крім голосу
(ElevenLabs Voice Isolator), не брати: зникає атмосфера.
