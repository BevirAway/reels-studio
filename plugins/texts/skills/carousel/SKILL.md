# Каруселі

1. Текст: тема → 5–9 слайдів. Слайд 1 — хук (коротко, великим шрифтом), далі одна думка на слайд, останній — висновок
   або питання/дія. Текст її голосом (навичка `texts:captions`). Показати текст слайдів їй до оформлення, якщо тема нова.
2. Оформлення: `Мій стиль/STYLE.md` (кольори, шрифти, як виглядають її заголовки) + шрифти з `Мій стиль/fonts/`.
   Шаблон — `${CLAUDE_PLUGIN_ROOT}/templates/slide.html` (змінні кольорів і шрифтів угорі). Скопіювати в
   `Проєкти/<дата> <назва>/slides/`, разом зі шрифтами (`fonts/`), і зробити по HTML на слайд (`01.html`, `02.html` …).
3. Картинки: `~/.studio/bin/py ${CLAUDE_PLUGIN_ROOT}/scripts/render_slides.py <папка slides> [--size 1080x1350]` →
   PNG поруч. Переглянути кожен PNG (Read): текст не вилазить, читається з телефона (не дрібніше 34 px), відступи рівні.
4. Готове — у `Готово/<дата> <назва>/` (`01.png`…) + підпис окремим файлом. Обкладинка рілса — той самий шаблон з
   `--size 1080x1920`.
Дизайн без «ІІшності»: суцільний фон її кольору, сміливий заголовок, багато повітря, один акцент; без градієнтів,
скла, світіння, іконок-клипартів. Малюнки — прості лінії SVG (рука, стрілка, людина), як у неї.
